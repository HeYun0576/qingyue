## 完整介绍版

### 标题

轻阅：免安装、可离线使用的 Windows Markdown 阅读编辑器，附 Lite 轻量版

### 正文

分享一个正在维护的开源小工具：**轻阅（QingYue）**。

它想解决一个很日常的问题：双击打开一份本地 Markdown，既能舒服地阅读，也能随手修改，不用为了看一篇文档先登录账号或启动一整套工作空间。

目前提供 Windows x64 便携包，下载 ZIP、解压、运行即可。

主要做了这些：

- **左写右看**：Markdown 编辑与实时预览分栏显示；也能单独编辑或只看正文。
- **长文阅读**：独立目录、全屏阅读、缩放、翻页、书签和批注，方便回到需要的位置。
- **本地文档整理**：多标签页、文件夹搜索、历史快照，以及可选的退出后恢复。也可以设置每次干净启动。
- **按习惯阅读**：明亮、深色、护眼、纸张与跟随系统主题；支持字体大小和行宽设置。
- **保存与分享**：支持 PDF、HTML、Markdown、TXT 等导出；Markdown 预览支持表格、代码高亮、公式和 Mermaid 图表。

有两个版本：

- **完整版 1.3.4**：包含更多工具，如 Word/Excel 轻量编辑、白板、思维导图、文件对比等。
- **Lite 0.1.2**：去掉 Office 和重型工具，专注 Markdown、文本和代码文件的阅读编辑。

也说明几个边界：Lite 仍基于 Electron，不是几 MB 的原生程序；Office 是轻量模式，不替代完整 Word/Excel；朗读使用系统已安装语音。文档在本机处理，但文档中的远程图片、音频和外部链接仍可能联网。

项目已按 MIT 协议开源，界面目前为中文，仓库另有英文介绍。

## 短帖版

分享一个开源 Windows 小工具：**轻阅 QingYue**。免安装、无需账号，可离线阅读编辑本地 Markdown，支持左写右看、目录跳转、阅读缩放、深色主题和 PDF/HTML 等导出。提供完整版及去掉 Office、白板等重型工具的 Lite 版。

下载 ZIP，解压即可用。欢迎试用、反馈问题；觉得有用也欢迎 Star。
